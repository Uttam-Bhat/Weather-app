# Weather Application

A responsive weather app that shows current weather, forecasts, and air conditions for any location.

## Features
- Current weather display
- Hourly forecast
- Air conditions (humidity, wind, heat index)
- 3-day forecast
- Sunrise/sunset times
- Search any city worldwide
- Responsive design for all devices

## Tools & Technologies
- **HTML5** - Structure
- **CSS3** - Styling and responsive design
- **JavaScript** - Functionality and API calls
- **WeatherAPI.com** - Weather data source
- **SVG Icons** - Weather and UI icons

## How It Works
1. User searches for a city
2. App fetches weather data from WeatherAPI.com
3. Displays current weather, forecast, and air conditions
4. Responsive layout adapts to screen size

## Setup
1. Get free API key from [WeatherAPI.com](https://www.weatherapi.com/)
2. Add your API key in `scripts.js`
3. Open `home.html` in browser

## Files
- `home.html` - Main page
- `styles.css` - All styling
- `scripts.js` - Weather functionality
- `Sunrise.svg`, `Sunset.svg`, `windimg.png` - Icons
